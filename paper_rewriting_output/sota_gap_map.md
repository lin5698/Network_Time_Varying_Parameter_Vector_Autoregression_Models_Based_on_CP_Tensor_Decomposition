## Strongest Available Gap

Many computational models are evaluated by fit, prediction or reconstruction error, while later scientific use asks the fitted object to evaluate a modified structural argument. The unresolved question visible in the approved corpus is not whether topology can appear in a model, but whether the representation retained after learning is sufficient for a declared topology-indexed operator query, and whether the method can certify availability before returning a response.

This is a **query-sufficiency and certification gap**, not a CP gap. **Serves: novelty / significance / clarity.**

## Strongest Currently Supported Contribution

- Exact family-specific factorization logic for one-hop operators is manuscript-usable within its assumptions.
- A non-equivalent second-order graph-filter family has a complete proof packet, exact negative and positive fixtures, and an independent proof-review `PASS`; its manuscript activation is not yet released.
- A controlled CP comparison is usable only in its named simulation regime.

The current evidence therefore supports a theory-led representation principle more strongly than it supports a broad estimator-performance claim. **Serves: rigour / clarity.**

## Dimensions This Paper Should Not Compete On

- Universal forecasting accuracy.
- Generic network-dynamics discovery.
- Causal effects of topology or policy.
- Network formation or latent-topology reconstruction.
- “All datasets, all metrics” estimator dominance.
- Open-source or fully public raw-data claims while licence and provider constraints remain.

## Strategic Consequence

The ambitious NCS route should define a new competition: **scientific operator queries that remain certified after learning**, with performance evaluated only inside the certified target and declared stable regime. This turns endpoint availability and principled abstention into the comparison axis, while leaving forecasting and causal discovery to methods designed for those tasks. **Serves: novelty / significance / rigour / generality.**
