Date: 2026-07-26

Status: active visual-writing contract. This document does not activate blocked
E3, RCEP or NYC evidence and does not change either controlling audit state.

## Sequence-level conclusion

A learned evolving-network representation can return a topology-indexed
response only when the requested query factors through what the representation
retains; separated structure or a verified inverse makes the query callable,
and the current numerical evidence supports recovery only in the declared
controlled regime.

## Shared visual system

- Backend: Python only for source generation, previewing, export and QA.
- Target: Nature Computational Science, double-column width (about 183 mm).
- Primary formats: editable SVG and PDF; secondary 600 dpi TIFF or PNG preview.
- Typography: Arial/Helvetica-compatible sans serif; lowercase bold panel
  labels; editable SVG text.
- Palette: warm signal `#C85A3A` for query-capable separated structure, cool
  comparator `#367C8D` for a certified alternative/comparator, neutral greys
  for context and unavailable endpoints. Red is not used as a failure fill.
- Hierarchy: one dominant panel per figure; whitespace and alignment replace
  equal framed dashboard tiles; direct labels replace repeated legends.
- Evidence rule: every quantitative mark must trace to a released source-data
  artifact. E3-v2 quarantine, RCEP and NYC values are excluded.

## Figure 1: The callable object

Core conclusion: retaining query arguments makes one fitted coefficient path
callable at observed, direct-only and supplied frozen topologies.

Figure archetype: schematic-led composite.

Panel map:

- **a, hero (about 60% of area):** observed histories enter a learned object
  that retains direct and network-mediated blocks; a separately supplied
  topology enters only at readout; the object returns a topology-indexed
  operator and finite-horizon response.
- **b, supporting:** three direct-labelled calls from the same fitted path:
  observed topology, zero network mediation and frozen topology. The fitted
  state, shock and horizon are visibly shared.
- **c, quiet boundary strip:** a collapsed total map without a verified inverse
  abstains from a genuine topology-substitution query. This is subordinate to
  the positive capability and uses neutral grey.

Evidence hierarchy:

- Hero evidence: definition of the separated topology-indexed operator and
  callable readout.
- Validation evidence: same fitted path supports three declared evaluations.
- Boundary: collapsed representation is outside target unless accompanied by
  a verified inverse.

Reviewer risk: readers may mistake topology substitution for refitting or may
read abstention as the paper's main contribution. The schematic must show one
stored state feeding all calls and make capability visually dominant.

Serves: novelty / clarity / visual communication.

## Figure 2: The query certificate

Implementation status, 2026-07-26: the Python-only source, editable SVG/PDF
and 600 dpi PNG are generated and visually audited. The manuscript builder
places this asset as Figure 2 and moves the released numerical validation
asset to Figure 3. This source integration does not authorize a full build or
change either controlling audit state.

Core conclusion: query preservation is decided by factorization through the
retained representation, with an exact unrestricted negative result and a
constructive structured positive route.

Figure archetype: asymmetric schematic-led theorem figure.

Panel map:

- **a, hero:** factorization diagram `Q = h o T` with retained object `T`,
  requested query `Q` and certified evaluator `h`; use direct labels for
  `callable` and `not determined`.
- **b, exact unrestricted certificate:** two parameter pairs share
  `D=A+BW0` but disagree at `W1`; visually isolate `W1 != W0` as the source of
  non-factorization. No large failure badge.
- **c, structured positive certificate:** diagonal blocks plus zero-diagonal
  topology admit the rowwise inverse under the stated row condition; show
  separated blocks or verified inverse converging on the same callable query.
- **d, endpoint classification strip:** separated CP and Tucker define the
  declared topology-response endpoints; collapsed and no-network controls show
  neutral outside-target marks for unsupported endpoints.

Evidence hierarchy:

- Hero evidence: Proposition 1 factorization criterion.
- Constructive evidence: Corollary 1 rowwise inverse.
- Operational consequence: endpoint availability precedes error comparison.

Statistics/source data: panels a-c are mathematical schematics and require no
statistical marks. Panel d is categorical and must trace to the frozen endpoint
classification registry, not to recovery outcomes.

Reviewer risk: a broad reader may conflate the unrestricted negative theorem
with the diagonal estimator. Panel c must make the structured exception
spatially adjacent and equally explicit.

Serves: novelty / rigour / clarity / generality / visual communication.

## Figure 3: Supported operating regime

Implementation status, 2026-07-26: the Python-only source, editable SVG/PDF
and 600 dpi PNG are generated and visually audited. The generator reads the
released controlled benchmark and frozen strict gate, verifies 20 replications
per reported scale and refuses if the strict counts drift. The old dense
validation asset remains supplementary traceability material. No full
manuscript or figure-package build was run.

Core conclusion: endpoint-preserving reconstruction improves recovery in the
declared controlled design, while the strict native test bounds rather than
erases that result.

Figure archetype: asymmetric quantitative composite.

Panel map:

- **a, hero:** controlled `N=15` and `N=30` effective-operator recovery for CP
  versus the declared unrestricted local comparator, with source-defined
  center and interval.
- **b, paired response evidence:** the corresponding network-channel response
  or GIRF error under the same controlled rows.
- **c, endpoint availability key:** compact categorical strip distinguishing
  callable endpoints from outside-target controls so absent scores are never
  read as zero error.
- **d, quiet operating-boundary inset:** strict native qualification counts
  `CP 0/16`, `Tucker 6/16`, and `Tucker native 0/8`. The inset is factual and
  neutral; it defines the domain of the positive claim rather than becoming a
  red failure dashboard.

Evidence hierarchy:

- Hero evidence: released controlled recovery comparison at `N=15/N=30`.
- Supporting evidence: response recovery on the same declared endpoint.
- Boundary: released strict native qualification counts.
- Supplementary only: `N=50` stress rows, dense topology-measurement stress,
  projected graph-feature diagnostics and all blocked E3 outputs.

Statistics/source data:

- State the replication unit, number of replications, center and interval in
  the caption using the released benchmark source.
- Preserve axes and error definitions across panels a-b.
- Do not infer a statistical test or significance level that is absent from
  the source artifacts.

Reviewer risk: a compact boundary inset could be mistaken for universal
failure or hidden qualification. The caption must state that endpoint
availability and numerical recovery are distinct, and that the positive claim
is restricted to the controlled design.

Serves: significance / rigour / clarity / reproducibility / visual
communication.
