## Integrity Checks

### A. Ground-Truth Provenance: PASS

Simulation truth is generated before outcomes in
`scripts/experiments/r006c_endpoint_protocol.py`. Endpoint truth is constructed
from simulated `M_ref`, `B` and endpoint topology in
`scripts/experiments/r006c_endpoint_metrics.py`. True `B` is available only to
the explicitly ineligible `oracle_b_anchor` mechanism diagnostic.

### B. Score Normalization: PASS

Operator error uses the truth norm. The response ratio uses the declared
zero-operator baseline while raw response error remains stored. Raw,
stability-qualified and projected metrics are separate; projected sensitivity
does not enter promotion gates.

### C. Result Existence and Numeric Alignment: PASS

All corrected artifacts exist, the primary CSV independently reproduces the
stored summary and promotion records, and the completed grid has zero missing
or silently deleted rows. The administrative records that triggered the audit's
overall `WARN` are updated after this report.

### D. Path and Test Integrity: PASS

The live path reaches construction verification, grid execution, generation,
fitting, endpoint evaluation, promotion/grid gates and artifact writers. Fresh
verification passed `44/44` R006c tests and `69/69` experiment tests.

### E. Leakage and Causality: PASS

Held-out topologies are absent from `EstimationInputs` and first enter after
fitting. For validation position `p`, fused selection reconstructs only
`local_tensor[:, :, :p+1]` and scores the final prefix coefficient. The
regression test proves a later validation estimate cannot affect an earlier
validation score.

### F. Duplicate and Provenance: PASS

The protocol, chronological-correction addendum and all seven transitive code
hashes match both pre-outcome construction artifacts and both result payloads.
Historical pre-correction outputs remain isolated. Corrected primary and repeat
runs have zero non-runtime differences.

### G. Scope and Language: PASS

The evidence is limited to the frozen `N=20`, `T=200` simulation protocol with
two layers, two stability levels, two approximation levels, three separation
levels and ten seeds. It does not license a broad empirical or general
topology-switch superiority claim.

### H. Gate Fidelity: PASS

Promotion requires one fixed candidate to pass both endpoints in all 16 cells,
including strict operator and zero ratios below one, at least 10% paired median
improvement against all three comparators, at least 80% joint wins and the
worst-endpoint gate. Stress, `eta=0.02`, collapsed, oracle and projected rows
cannot rescue a failed required cell.
