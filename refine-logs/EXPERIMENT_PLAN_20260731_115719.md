# E4：Domain-stable query recovery 实验计划

**问题**：在不访问 held-out topology、不中途重拟合且不放宽稳定阈值的条件下，query-preserving estimator 能否在整个声明 topology domain 上返回稳定端点，并在两个非等价 operator family 中形成可信的 held-out recovery 证据？

**方法主线**：在现有 finite-basis query certificate 上增加 query-independent 的 domain-uniform stability envelope。对一次归一化且满足 $\lVert W\rVert_\infty\leq1$ 的拓扑，Family 1 与 Family 2 的对角 block operator 都满足

$$
\rho\{G(W)\}\leq\lVert G(W)\rVert_\infty
\leq \max_i\sum_j|c_{j,i}|.
$$

拟合后、任何 query 出现前，将每个节点的 retained block vector 投影到 $\ell_1$ 半径 $\eta=0.90$。同一投影后 coefficient path 用于 observed、interpolation 和 cross-generator queries；评价阈值仍为 0.98。

**日期**：2026-07-31

**必须排除的替代解释**：

- 稳定性来自把 0.98 threshold 调高、删除 cross-generator、选择稳定 seed 或评价后缩放 operator。
- candidate 使用了 held-out topology、held-out truth 或 response error 选择 rank/constraint。
- fixed-rank 优势只来自 comparator endpoint 不一致或 comparator 失败后仅比较成功子集。
- Family 2 实际退化为 $A+BW$ 或把 $W^2$ 当作预处理特征后重新命名。

## Experiment Blocks

### B1. Exact domain-stability certificate

- **Claim tested**：C1。
- **设计**：证明 $\max_i\sum_j|c_{j,i}|\leq\eta$ 对 Family 1/2 和所有 $\lVert W\rVert_\infty\leq1$ 查询给出 $\rho\{G(W)\}\leq\eta$；$W^2$ 不重新归一化。
- **Fixtures**：signed row-normalized topology、directed sparse topology、latent-position topology；系数恰在 envelope 内、越界后投影、零向量三类。
- **Success criterion**：精确/浮点 fixture 均满足 block envelope；任何合法 query 的 spectral radius 小于或等于 0.90；投影不读取 query。
- **Failure interpretation**：若推导只对某个 generator 成立，停止 E4，不运行 grid。
- **Target**：Methods proposition + Supplementary proof/contract。
- **Priority**：MUST-RUN。

### B2. End-to-end constrained native interface

- **Claim tested**：C1。
- **Compared systems**：`local_structured`、`causal_temporal_smoother`、`fixed_rank_basis`，全部保留相同 native blocks 并使用相同 envelope。
- **Implementation contract**：projection 在 fit 输出冻结时执行；validation、evaluation、recursive bootstrap 和 bootstrap retuning 共用该 route；query topology 不出现在 estimator API。
- **Success criterion**：fixture-only tests 先 RED 后 GREEN；所有方法在强制越界的 synthetic fit fixture 上返回 envelope 内 blocks；bootstrap refit 不能绕开 projection。
- **Failure interpretation**：任一 alternate fit path 绕开约束，candidate 不可物化。
- **Target**：reproducibility package，不作为数值结果。
- **Priority**：MUST-RUN。

### B3. Frozen v4 candidate and static preflight

- **Claim tested**：执行完整性，不测试科学结果。
- **Bindings**：source closure、v4 input JSON、$\eta=0.90$、0.98 evaluation threshold、20 seeds、N=20/50、H=4/12、两 query classes、三 methods、八项 pre-outcome artifacts、新 quarantine root。
- **Hard refusals**：缺少 exact candidate binding、source/hash drift、旧 authorization、已存在 output root、threshold drift、stable-cell selection 或任何 excluded route。
- **Success criterion**：所有 schema/semantic validators 通过；缺少 production trust evidence 时在 generator/fit 前拒绝。
- **Failure interpretation**：只修 preflight，不运行科学 grid。
- **Priority**：MUST-RUN。

### B4. Two-family held-out recovery grid

- **Claim tested**：C2。
- **Grid**：Family 1/2 × N=20/50 × interpolation/cross-generator × H=4/12；seeds 4101-4120；chronological train/validation/evaluation partitions 不变。
- **Selection**：每个 method 仅使用 observed-topology one-step validation loss；trial budget 仍为 3；tie-break 不变。
- **Primary metrics**：response MSE、operator MSE、status/failure rate、paired panel-level log error ratio；prediction loss 仅作为 selection record。
- **Primary success criterion**：所有预声明 records 保留；candidate 不得有高于 comparator 的 failure rate；`fixed_rank_basis` 在每一个 family × scale × query × horizon 主单元的 paired median response MSE 都低于 `local_structured` 和 `causal_temporal_smoother`。任一 cross-generator 或 Family-2 单元反转即阻断跨 family held-out recovery claim。
- **Secondary evidence**：operator MSE 与 response MSE 方向一致；等权 cell-level paired log-ratio 置信区间；runtime/selection/failure inventory。
- **Failure interpretation**：若仅 interpolation 通过，主张限于 interpolation；若 Family 2 或 N=50 失败，保留为 operating boundary，不改 generator、不删 cell。
- **Target**：future Main Figure 4 或替换现有 Figure 3 的扩展 panel，只有独立审计后才决定。
- **Priority**：MUST-RUN。

### B5. Uncertainty, duplicate and claim audit

- **Claim tested**：C2 的可信度，不单独制造新 headline。
- **Procedure**：H=4、每个 family × scale × query cell 的 20 panels；每 panel 80 recursive residual moving-block bootstrap replicates；每 replicate 完整 retune/refit并使用同一 envelope。
- **Report**：simultaneous coverage、mean width、所有 bootstrap statuses；任何失败 replicate 使该 interval 无效。
- **Promotion gate**：isolated duplicate 的 deterministic fields/summary 必须一致；fresh result-to-claim reviewer 必须确认无 number inflation、common-completion bias 或 cross-cell pooling。
- **Failure interpretation**：coverage 或 width 不合格时，不提出 uncertainty claim；这不允许改 bootstrap 后重用同一 candidate identity。
- **Priority**：MUST-RUN。

## Compute and Data Budget

- 仅使用现有 synthetic route、NumPy 和本机 CPU；不安装新依赖，不使用 RCEP/NYC。
- 完整成本在 fixture-only timed smoke 后记录；未测量前不提供虚构时长。
- 最大成本来自 2 families × 2 scales × 2 query classes × 20 panels × 80 bootstrap refits。
- 若预算过高，只能在 candidate freeze 前统一减少 bootstrap replicates 并生成全新 protocol；不得执行后删减失败 cells。

## Risks and Mitigations

- **约束保证稳定但损害 recovery**：所有 methods 使用同一 envelope；以 paired recovery 而非稳定率单独判断价值。
- **约束只是 evaluation-time stabilization**：projection 必须发生在 fit 输出冻结处，query API 只能读取已固定 blocks。
- **truth/estimator contract 不对称**：truth 保持原有 <0.8 construction；estimator 使用 0.90 envelope；两者和 0.98 failure threshold 分开记录。
- **区间过宽**：coverage 和 width 同时报告；不允许只宣传 coverage。
- **结果选择诱因**：每个 family/scale/query/horizon 单独报告，跨 generator 失败不能被 pooling 抵消。
