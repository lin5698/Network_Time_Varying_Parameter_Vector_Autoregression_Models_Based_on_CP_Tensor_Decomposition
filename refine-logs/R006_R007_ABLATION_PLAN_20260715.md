# R006/R007 Reviewer-Led Ablation Plan

**Date:** 2026-07-15  
**Trigger:** R005 passed its frozen exact-rank pilot gate, but absolute recovery and model-alignment questions remain.

## Reviewer Questions Raised by R005

1. Do CP/Tucker gains survive when the truth is only approximately rank 3?
2. Are gains caused by generic low-rank compression rather than CP-specific structure?
3. Does the method require smooth temporal weights, a fixed spatial subspace, or both?
4. Can a strong temporal-only fused baseline match the low-rank methods?
5. Do relative gains persist when absolute query recovery is required?

R005 cannot answer these questions because its truth and fitted rank are both 3, the path has a fixed smooth factorization, temporal spline improves only modestly, and several viable cells retain median relative query-operator error around 0.9 to 1.6. Raw response errors also require normalization before comparisons across stability levels.

The a3=0.50 cell is a frozen negative-boundary cell and need not pass. Rank 5 cannot substitute for the rank-3 gate.

## R007: Temporal-Path 2 x 2 Misspecification

R007 holds N=20, T=240, window=80, sigma=0.25, separation=0.15 and rho in {0.80, 0.95}. It crosses temporal continuity with spatial-subspace stability:

| Continuity | Spatial subspace | Definition | Question |
| --- | --- | --- | --- |
| smooth | fixed | R005-style smooth weights and fixed rank-3 factors | anchor |
| abrupt | fixed | one 30% Frobenius jump at t=144 | does CP require temporal smoothness? |
| smooth | rotating | continuous rotation toward an orthogonal subspace by 30 degrees | can fixed global rank represent the path? |
| abrupt | switched | 30-degree subspace switch at t=144 | frozen difficult region |

Results must be reported separately for the change-point band t=134-154, the pre-break far band t=104-123 and the post-break far band t=224-238. CP/Tucker rank 6 is diagnostic only in rotating cells. Fused-TV is expected to be strongest near an abrupt boundary; CP/Tucker must remain competitive in far bands or the claim must explicitly exclude abrupt changes.

## Run Order

1. Add zero-operator normalization and a tested fused-TV temporal baseline.
2. Run a two-seed R006 smoke check for approximation calibration and schema.
3. Run R006 a3=0.10/0.25 cells, followed by the exact anchor and a3=0.50 negative boundary.
4. Run R007 fixed smooth/abrupt cells before rotating/switching cells.
5. Expand to R011-R017 only if absolute recovery gates pass.

## Compute Decision

R006 is expected to produce 80 DGP replications and 720 method rows. R007 is expected to produce approximately 480 method rows. Both fit comfortably in Apple M5 CPU/Accelerate memory. Mac GPU migration is deferred to R010 because these small tensor factorizations are unlikely to amortize backend and transfer overhead.

## Intentionally Deferred

The following are not part of R006/R007: full N/separation/horizon sweeps, topology noise, native GNNs, rank 1-10 searches, projected-stability variants and Mac GPU benchmarking. They belong to R008, R010, R012-R017 and R022 or later.
