# R005 Separation x Stability Pilot Protocol

**Freeze date:** 2026-07-15  
**Role:** M1 stop-go pilot; not manuscript-facing headline evidence  
**Compute route:** Apple M5 CPU through NumPy/SciPy linked to Apple Accelerate

## Objective

Test whether the theory axes can be controlled numerically and whether block-preserving reconstruction improves finite-horizon response recovery in at least one declared operating regime. This pilot does not establish scale, rank-selection, native graph-baseline or uncertainty claims.

## Fixed Design

- Panel size: `N=20`, `T=200` after initialization.
- Seeds: `240100` through `240109`.
- Local trailing window: 80 transitions.
- True separated coefficient tensor rank: 3.
- Innovation standard deviation: 0.25, Gaussian.
- Ridge penalty in the common local estimator: 0.001 after dividing cross-products by window size.
- Separation axis: topology-path variation amplitudes `0.02`, `0.15`, `0.45` around a fixed row-normalized base topology.
- Stability axis: date-specific frozen-base query-operator spectral radii `0.50`, `0.95`, `1.01`, imposed using the largest absolute eigenvalue.
- Evaluation dates: final 30% of reconstructed dates.
- Response horizon: 8.
- Stability-qualified threshold: spectral radius strictly below 0.98 for both truth and estimate.
- Projection sensitivity target: 0.95; this sensitivity never replaces the raw response error.

The direct and network blocks share three spatial components with smooth, non-constant temporal weights. A common date-specific scale maps the operator evaluated at the fixed base topology to the declared spectral-radius axis while preserving the separated rank-three representation. The observed panel is generated using the evolving topology path. That path varies smoothly around the same base topology; when variation approaches zero, network exposures become linearly predictable from direct lags within a rolling design.

## Compared Methods

All methods start from the same one-sided local ridge estimates.

| Method | Fixed pilot configuration | Target retained |
| --- | --- | --- |
| `local` | no reconstruction | direct/network blocks |
| `cp_rank3` | deterministic two-start CP-ALS, rank 3 | direct/network blocks |
| `tucker_333` | HOSVD ranks (3, 3, 3) | direct/network blocks |
| `spline_df10` | cubic regression-spline projection with 10 temporal basis functions | direct/network blocks |

The fixed rank uses the known pilot DGP rank and is therefore diagnostic only. R006 and R015 remain mandatory for approximate rank and non-oracle selection.

## Metrics

Primary:

- relative frozen-base query-operator Frobenius error;
- raw frozen-base finite-horizon response error averaged over shocks and horizons 0 through 8;
- stability-qualified response error, missing whenever truth or estimate fails the threshold;
- estimated instability rate.

Secondary:

- projected response sensitivity, reported separately;
- one-step observed-topology reconstruction RMSE;
- normalized residualized-exposure minimum eigenvalue;
- method runtime and failure status.

## Frozen Stop-Go Rules

R005 passes only if all of the following hold:

1. The median separation diagnostic is strictly increasing across the three topology-variation levels, and the high/low ratio is at least 4.
2. The maximum absolute deviation between imposed and measured true spectral radius is below `1e-8`.
3. At least one block-preserving smoother reduces median paired raw response error by at least 10% relative to local estimation over the viable cells (`separation >= 0.15`, `rho <= 0.95`).
4. At least 95% of the expected replication-method rows finish without numerical failure.
5. Raw, stability-qualified and projected-sensitivity errors remain separately stored; unstable truth cells cannot contribute a stability-qualified response error.

Failure narrows or redirects the method claim. It must not be repaired by silently changing the grid, deleting seeds or substituting projected errors.
