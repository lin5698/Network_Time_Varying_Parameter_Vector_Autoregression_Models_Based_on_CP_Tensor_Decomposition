## Consequences For This Manuscript

1. Lead with the computational object, not CP, RCEP or a predictive score: a reconstructed path must preserve a callable topology argument for a stated response query. Serves: novelty / clarity.
2. Make the negative control visible before recovery numbers: a collapsed map can return a fitted-topology total response while leaving topology-substitution endpoints outside its declared target. Serves: rigour / visual communication.
3. Treat the endpoint-aware native failure as a stopping rule rather than hiding it after a favourable controlled benchmark. Serves: rigour / generality.
4. Reserve transfer language for a named held-out topology-family or source-target test. A second application alone is not evidence of transfer. Serves: generality / clarity.
5. Keep network formation, causal topology effects and generic dynamics discovery outside the claim set. They are neighboring research programmes with different data and evidence requirements. Serves: novelty / rigour.
