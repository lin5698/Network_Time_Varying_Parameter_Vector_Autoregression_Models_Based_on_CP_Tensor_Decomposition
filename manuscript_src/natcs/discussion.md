Query-certified operator learning makes scientific computability an explicit property of a learned model. In the present supplied-topology setting, fitting an observed trajectory is not sufficient to guarantee that the fitted object can evaluate a response under a modified topology. The representation must retain, or recover through a verified inverse, the arguments of that computation while the coefficient path, shock normalization and horizon remain fixed. This changes how a response model is evaluated: endpoint availability is established before identification, recovery and finite-horizon interpretation. A model that does not define the requested endpoint abstains from that query; it does not return a zero-valued or numerically scored surrogate. For the present operator class, the result concerns fixed-path scientific computation, not a causal effect of topology.

The factorization results translate this principle into a representation-design criterion. Theorem 1 classifies finite-basis row-separable queries by an exact kernel inclusion, with an equivalent row-space test. It covers one- and two-hop bases; the two-hop class is strictly larger on every declared topology domain containing the directed three-cycle $P$. Proposition 1 then gives the unrestricted one-hop boundary, while Corollary 1 supplies a constructive diagonal inverse. Together, these results show that compression is compatible with a scientific query exactly when the query factors through the compressed object. Separation guarantees this property, but a verified inverse can also restore it.

The numerical results establish the value of endpoint-preserving reconstruction in the experiment designed to test it. In the replicated controlled $N=15$ and $N=30$ design, CP reduced effective-operator and finite-horizon unit-shock response error relative to unrestricted local rolling estimation while returning the same declared endpoint. The separate endpoint-aware qualification is reported in Supplementary Note 4. Together, these results establish a computational capability under a declared design, endpoint and comparator.

This criterion complements other representation-sensitive programmes in temporal and network science. Dynamic communities, temporal memory, link prediction and contagion each require representations matched to their native scientific targets [@peixoto2017; @williams2022; @he2024seq; @murphy2021]. Equation discovery, inverse reconstruction and topology-formation modelling target governing laws, interaction structures or endogenous network evolution [@yu2026nsr; @delabays2025; @li2026nemarl]. Query certification asks a downstream-use question shared by compatible learned models: does the retained object still expose the argument required by the scientific computation? Here the argument is a supplied topology and the computation is a fixed-path response. The finite-basis theorem extends the representation test beyond one-hop exposure, while recovery remains family-specific.

The broader design implication is constructive. Scientific learning systems should specify downstream computations before choosing what to compress. For each operator family, the representation certificate identifies the required arguments, while same-endpoint recovery and stability evidence qualify numerical use. Here the theorem spans one- and two-hop finite bases, and the recovery study establishes the one-hop implementation. This alignment between query, representation and evidence supplies a direct rule: preserve the requested computation, provide a verified inverse or abstain from the query.
