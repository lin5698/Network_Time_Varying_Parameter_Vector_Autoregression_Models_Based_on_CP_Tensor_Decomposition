Scientific models are rarely fitted only to reproduce the data on which they were trained. They are subsequently reused to evaluate perturbations, compare structures or propagate a fixed input under a modified environment. For an evolving weighted network, one such computation holds a fitted coefficient path, shock normalization and response horizon fixed while replacing a supplied exposure topology. This matched topology-substitution query asks how the same shock would propagate under an observed, removed or benchmark topology. A representation can reproduce the observed trajectory yet discard the direct and network-mediated components required by this later calculation. Fit and scientific computability remain distinct objectives. We call retention of the arguments required by the later computation query preservation; it defines a fixed-path readout and does not identify a causal effect of topology.

Representation-sensitive questions recur across temporal network science. Dynamic-community models retain evolving mesoscale structure, while memory representations preserve heterogeneous temporal dependence. Link-prediction algorithms specify information at the target layer, and contagion models encode which local dynamics transfer across structures [@peixoto2017; @williams2022; @he2024seq; @murphy2021]. Geometry-dependent operator learning likewise keeps a variable geometry explicit at evaluation [@yin2024dimon]. Network-dynamics discovery, inverse reconstruction and network-evolution models instead target governing laws, interaction structures or topology formation [@yu2026nsr; @delabays2025; @li2026nemarl]. Together, these advances show that the retained representation determines which downstream computations remain possible. They leave a different question unresolved: after temporal reconstruction, can the learned object certify that a supplied topology remains a callable argument of the requested response?

Time-varying autoregressions accommodate drifting coefficients [@primiceri2005; @chan2020; @banbura2010], while low-rank decompositions regularize high-dimensional coefficient paths [@harshman1970; @kolda2009; @chen2024]. Spatial, network and global autoregressions encode cross-unit exposure and support scenario or impulse-response analyses [@pesaran2004; @chudik2016; @lesage2009; @elhorst2014]. GVAR formulations can also use time-varying trade weights [@pesaran2004; @chudik2016]. Yet none of these ingredients certifies that a requested computation remains available after reconstruction. We derive an exact kernel criterion for row-separable operators built from any declared finite topology basis. Its equivalent row-space form covers one- and two-hop bases, while explicit witnesses and inverses delineate when compression removes or preserves the query. Query evaluability is a property of the retained representation and any verified inverse; it is no automatic consequence of smoothing or predictive fit.

Here we introduce query-certified operator learning to make this property explicit. The framework separates four requirements for a topology-dependent response: definition by the fitted object, identification by the design, numerical recovery and finite-horizon stability. The desired scientific response is specified before fitting, and the learned object is tested for a factorization that preserves its topology argument. Our finite-basis theorem supplies the representation criterion; one- and two-hop bases show that it is not tied to a single operator expression. A CP reconstruction instantiates the endpoint-preserving object in the one-hop controlled study, while Tucker and collapsed representations provide structural and numerical comparators. Controlled experiments evaluate recovery only after endpoint availability has been assigned. The resulting framework makes downstream scientific computation an explicit target of representation design.
