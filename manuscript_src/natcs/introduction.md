Models of evolving networks are often used for a question that is counterfactual in topology but fixed in dynamics: how would the same shock propagate if the exposure graph were replaced, removed or held at a benchmark state? Answering this question requires more than a fitted trajectory. The fitted object must still accept topology as an input while holding its coefficient path, shocks and response horizon unchanged.

Temporal reconstruction can remove that capability even when it improves fit or prediction. If direct dynamics and network transmission are collapsed into a single map at the observed graph, an alternative-topology response is not defined without an additional inverse that recovers the separated components. This is a representation problem before it is an estimation problem. Work on dynamic communities, temporal memory, sequential link prediction and contagion learning likewise shows that stored representations determine which structures or dynamics remain measurable [@peixoto2017; @williams2022; @he2024seq; @murphy2021]. The unresolved operation here is whether topology-indexed response queries remain defined and estimable after smoothing a time-varying network model.

Existing tools address parts of this operation. Time-varying autoregressions allow coefficients to drift [@primiceri2005; @chan2020; @banbura2010]. Spatial, network and global autoregressions encode cross-unit exposure; GVAR formulations can use time-varying trade weights and support scenario and impulse-response analysis [@pesaran2004; @chudik2016; @lesage2009; @elhorst2014]. Low-rank decompositions regularize high-dimensional coefficient paths [@harshman1970; @kolda2009; @chen2024]. None of these method-family labels alone establishes that a reconstructed object defines or identifies a response at a supplied topology. The relevant distinction is query-specific: whether the stored representation retains the direct block, network block and topology action, or identifies them through a declared inverse under sufficient excitation. Endpoint availability must be verified at the fitted-object level.

Here we formulate the lag operator as $M_{k,t}(W)=A_{k,t}+B_{k,t}W$ and separate four requirements for a topology-dependent response: the endpoint must be defined by the fitted object, identified by the design, numerically recoverable and stable over the reported horizon. Controlled benchmarks compare separated CP and Tucker reconstructions with a collapsed-map structural negative control. The original scale benchmark tests recovery in a favourable controlled design; a stricter endpoint-aware benchmark tests whether that evidence extends to native held-out endpoints. Trade and mobility panels then illustrate fixed-path computation and its uncertainty boundaries. The contribution is a testable representation criterion, not a claim that every defined endpoint is statistically recoverable. Propagation denotes linear impulse transmission through a supplied exposure network; network formation, policy assignment and causal topology effects require separate designs.
