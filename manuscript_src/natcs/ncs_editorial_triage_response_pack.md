Boundary: use only the claims and evidence already present in the manuscript package. Do not strengthen any response with unconfirmed raw-data access, public DOI information, native temporal-GNN benchmarking, causal policy language or broad domain-generalization claims.

Serves: novelty / significance / rigour / clarity / generality / reproducibility / visual communication.

## Response-Ready Paragraph Bank

Use these paragraphs when a portal field, editor query or reviewer-response draft needs complete sentences. They add no new evidence. Keep the wording bounded unless the author worksheets close the corresponding external gate.

### Editor fit

The manuscript's computational contribution is representation-level. It asks which topology-substitution response queries remain measurable after a time-varying network model has been smoothed. The submitted operator keeps direct dynamics, network-mediated exposure and the supplied topology argument separately evaluable, so observed-topology, direct-only and frozen-topology readouts can be computed from one reconstructed path. The RCEP and NYC panels demonstrate the readouts; the transferable object is the endpoint-preserving response operator.

Tags: novelty / significance / clarity.

### Comparator scope

The benchmark is organized around response endpoints. Each fitted object first passes an endpoint-availability gate, and numerical recovery is scored only for readouts defined by that object. CP-network and Tucker-network preserve separated direct and network blocks. Projected graph-feature rows are stress tests after mapping local graph-feature fits into the submitted direct/network operator protocol. Native forecasting rankings for recurrent, attention or diffusion graph systems require a separate prediction protocol.

Tags: rigour / clarity / generality.

### RCEP interpretation boundary

The RCEP analysis is a fixed-path topology-substitution readout. It evaluates observed and 2016-2019 benchmark topology while holding the fitted coefficient path, shock normalization and response horizon fixed. The moving-block re-estimation interval and stability diagnostics set the boundary for reading direction and amplitude. The panel supports descriptive conditional propagation under supplied exposure matrices. Policy-effect identification and topology formation remain outside the submitted design.

Tags: significance / rigour / clarity.

### Reproducibility boundary

The review package supports regeneration of manuscript-facing figures, tables and numerical summaries from shipped derived evidence objects. The package also records environment snapshots, checksums, reproduction entry points, active-locality checks and release-safety scans. Raw-to-derived reconstruction is documented as a separate layer because several source blocks depend on third-party access conditions and helper checkouts. The submission claim is derived-evidence reproducibility for review, with raw-source constraints disclosed.

Tags: reproducibility / rigour / clarity.

### Fig. 2 readability

Fig. 2 carries the endpoint-availability and benchmark-recovery argument. Local QA shows that the standalone PDF/SVG is legible and the embedded manuscript page is usable with zoom, while the smallest labels remain dense at page scale. The journal portal preview decides whether the current figure can be retained. If panel a is unreadable in the portal and standalone source inspection is unavailable, the controlled redraw should enlarge the endpoint gate and move secondary stress details to the Supplementary Information.

Tags: visual communication / rigour / clarity.

## If An Editor Asks "Why NCS?"

Use this structure, not a longer defense:

1. Name the computational object: a topology-switchable response operator with an explicit topology argument.
2. Name the cross-domain query: evaluate one fitted dynamic-network path under supplied topology arguments.
3. Name the failure mode: collapsed smoothing can retain total responses while losing topology-substitution endpoints.
4. Name the evidence: endpoint gate, replicated operator/GIRF recovery rows, bounded empirical readouts and derived-evidence reproducibility.
5. Name the boundary: no causal topology formation, broad domain generality or native forecasting-ranking claim.

Suggested wording:

> The NCS fit is representation-level. In evolving weighted networks, the fitted object determines which response questions remain measurable after temporal smoothing. The topology-switchable response operator preserves the supplied topology argument, making matched observed, direct-only and frozen-topology readouts available from one reconstructed path.

## If A Methods Reviewer Challenges Comparators

Use this response order:

1. State the target first: recovery of the submitted topology-substitution response object.
2. Separate endpoint availability from numerical error.
3. Explain which rows are within target and which are outside target.
4. Point to Supplementary Table 1d for target alignment, tuning, projection, coverage, stability and endpoint hierarchy.
5. Offer a boundary: native temporal-GNN forecasting rankings require a different held-out prediction protocol.

Suggested wording:

> The benchmark is organized around the response endpoint. Each fitted object first passes or fails the endpoint-availability gate, then recovery error is scored only for defined readouts. Projected graph-feature rows stress recovery after mapping into the submitted operator protocol; they are not presented as native temporal-GNN forecasting rankings.

## If A Domain Reviewer Challenges RCEP Interpretation

Use this response order:

1. State that topology matrices are supplied exposure arguments.
2. State that the readout holds shocks, horizons and coefficients fixed.
3. State that the moving-block re-estimation interval defines the empirical boundary.
4. State that instability and stability-projected summaries limit amplitude interpretation.
5. Keep policy-effect identification outside the claim.

Suggested wording:

> The RCEP panel is a fixed-path topology-substitution readout. It compares observed and 2016-2019 benchmark topology while holding the fitted coefficient path, shock normalization and horizon fixed. The re-estimated interval and stability diagnostics set the boundary for interpreting direction and amplitude.
