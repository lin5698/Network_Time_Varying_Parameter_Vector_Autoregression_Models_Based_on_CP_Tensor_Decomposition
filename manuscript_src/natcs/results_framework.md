Query certification turns a topology-indexed response into an explicit computational interface. Before fitting, the query specifies the coefficient path to be held fixed, the supplied topology, shock normalization, response horizon and readout. Matched topology substitution then changes the topology argument at evaluation rather than refitting the model. Figure 1 shows the resulting capability. The learned object retains direct and network-mediated coefficient blocks and accepts a supplied topology. It returns observed-, direct-only- or frozen-topology responses under the same fitted path and shock. CP and Tucker are reconstruction or comparison layers for this object. The certificate asks the more basic question of whether their retained representations still make the requested response callable.

Theorem 1 gives the exact certificate for a row-separable finite-basis operator. A queried operator is callable from the retained object if and only if each retained row kernel is contained in its query-row kernel. Equivalently, the query row space must lie inside the retained row space. The condition has a direct interpretation: no coefficient direction discarded at fitting may become visible under the requested topology. Full column rank of every retained row design is sufficient for all supplied queries, but the kernel test also classifies rank-deficient cases.

The certificate is not confined to one-hop exposure. It applies to the bases $(I,W)$ and $(I,W,W^2)$, with $W^2$ denoting an unrenormalized two-hop operator. On every declared topology domain containing the directed three-cycle $P$, the two-hop function class strictly contains the one-hop row-separable class. At $P$, every row of $W^2$ lies outside the span generated by the corresponding rows of $I$ and $W$. This is a second, non-equivalent theoretical instance of the certificate. It does not supply two-hop recovery evidence; the numerical study below remains one-hop.

The one-hop cases make the general condition concrete. Proposition 1 considers unrestricted blocks and the retained map $D=A+BW_0$. The query $A+BW_1$ is determined by $D$ for every $(A,B)$ only when $W_1=W_0$. If the topologies differ, $(A,B)=(0,0)$ and $(-W_0,I)$ share the same retained map but return different queried operators. This construction concerns the representation, not identification of the diagonal estimator used below.

Declared structure supplies a positive certificate. Corollary 1 shows that a nonzero zero-diagonal exposure row recovers its direct and network coefficients through an explicit rowwise inverse. A zero fitted row supports only queries whose corresponding row is also zero. A representation can therefore preserve a topology query by storing separated blocks or by retaining a total map with a verified inverse. The collapsed ablation does neither, whereas the separated reconstruction keeps the declared endpoints callable.

Figure 2 makes this logic operational. The factorization diagram states the finite-basis kernel test. The exact pair construction shows why an unrestricted collapsed map cannot answer a genuine topology substitution. The adjacent inverse shows how declared structure restores the query. The endpoint strip assigns availability before any numerical comparison, preventing unsupported readouts from entering a benchmark as zero or finite error.

The certificate provides an explicit qualification of a returned response. If the representation lacks the required blocks or a verified inverse, the query is labelled `OUTSIDE TARGET`. No numerical error is assigned to an endpoint the method does not define. Availability alone is not sufficient. The design must distinguish direct from network-exposure regressors, and the estimator must recover the endpoint in the declared data-generating process. Finite-horizon interpretation must also satisfy the reported stability condition. These requirements answer different questions. Query certification determines whether the computation exists from the retained object; identification, recovery and stability determine whether an available computation supports the intended numerical interpretation.

The resulting sequence gives each experiment a precise computational question. The finite-basis theorem and stated inverse conditions establish endpoint availability. The singularity diagnostic tests design separation, the controlled benchmark measures recovery, and the bounded-power proposition qualifies finite-horizon transfer. Applied in this order, the protocol distinguishes a model that can answer the topology query from one that merely fits observed trajectories. This ordered evaluation is the practical contribution of query certification.
