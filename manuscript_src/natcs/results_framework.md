Matched topology substitution requires a lag operator whose network argument remains available after reconstruction. Figure 1 defines this object. The fitted path stores the direct coefficient block, the network-mediated block and the topology matrix as separate inputs. Topology-switchable means that the coefficients are held fixed after fitting and only the exposure matrix supplied to the response recursion is changed. Observed propagation uses the date-specific topology matrix, direct-only propagation sets network mediation to zero, and frozen-topology propagation uses the pre-period benchmark topology. The three evaluations share the same shocks, horizons and coefficient path.
