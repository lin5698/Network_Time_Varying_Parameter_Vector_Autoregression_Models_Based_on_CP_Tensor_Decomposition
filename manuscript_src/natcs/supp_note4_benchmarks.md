This supplementary note expands `Results > Validation and benchmarking` in the main manuscript, especially the arguments summarized in Figure 2, Table 1 and Supplementary Tables 1d, 2 and 3. The synthetic benchmark grid stresses the measurement problem across controlled dynamic-network settings. The main-text scale baselines are N=15, T=160; N=30, T=200; and N=50, T=240. The stress scenarios retain N=15 and vary rank specification, coefficient drift, topology volatility, network misspecification and shock tails. The CP-network, unrestricted local, Tucker-network and low-rank reduced-form scale rows use 20, 20 and 4 replications at N=15, N=30 and N=50, respectively. The projected graph-feature stress rows use matched 20-replication coverage at N=15, N=30 and in the high-topology-volatility, missing-edge and noisy-weight stress scenarios; their N=50 rows are bounded stress outputs with row-level coverage disclosed in Supplementary Table 3. The N=50 setting is reported only as a bounded stress check.

The comparator set is fixed throughout the benchmark:

1. unrestricted local rolling network estimation;
2. CP-network compression of the local coefficient tensor;
3. collapsed-operator CP, which first forms the effective operator $A_{k,t}+B_{k,t}W_t$ and smooths that collapsed reduced-form tensor;
4. Tucker-network compression of the same separated direct/network tensor;
5. low-rank no-network estimation, which omits the explicit network block;
6. sparse network TVP-VAR, which keeps the explicit direct/network block form and applies entrywise soft-thresholding to the local coefficient tensor;
7. graph-convolution VAR, which constrains lagged dynamics to a graph-filter span;
8. graph neural VAR, a lightweight neural graph surrogate that augments lagged direct and network exposures with nonlinear graph-neural features;
9. diffusion graph VAR, which adds second-order graph-diffusion features before projection back to the direct/network block form; and
10. recurrent graph-filter VAR, which adds a fixed rolling memory term before projection back to the same propagation objects.

The main-text benchmark figure begins with the readouts supported by each reconstruction target, then reports effective-operator and network-component GIRF error for replicated N=15 and N=30 scale rows and a separately labelled N=50 bounded stress row, together with frozen-topology error and instability under topology-measurement stress. Table 1 and Supplementary Table 2 retain the raw pair-level contribution error, total-GIRF error, one-step prediction error, peak memory, instability rate and failure rate. Effective-operator and total-GIRF errors are reduced-form recovery targets. Raw pair-level contribution, network-component GIRF and frozen-topology errors require a fitted direct/network decomposition and an evaluable topology argument. One-step prediction error is included as a prediction diagnostic. Blank structural endpoints mark readouts outside the fitted object's reconstruction target.

Supplementary Table 1d gives a compact reviewer-facing fairness audit. It condenses the benchmark target, tuning parity, projection contract, replication coverage, stability handling and endpoint hierarchy before the full row-level benchmark tables are read.

Benchmark tuning and projection rules are fixed in the benchmark script and summarized in Supplementary Table 1b. All regression-style local fits use the same ridge floor, 10^-6 on the normal-equation diagonal. The empirical RCEP and NYC grids are reported in Supplementary Table 1c, including every ridge and CP-rank candidate used for selection. The CP-network estimator uses the scenario rank specified by the validation design; the main scale rows set R=2, and the rank-under and rank-over stress rows set R=1 and R=3 to test rank misspecification. Tucker-network uses the matched R-by-R-by-R multilinear rank. Collapsed-operator CP and low-rank no-network use the same rank setting on their reduced-form tensors, so differences in output availability arise from the reconstruction target.

For projected graph-feature rows, the projection rule specifies the native fitted object, the mapping to a direct/network operator form, the allowed endpoint responses and separate stability reporting. The projection evaluates the common operator-recovery target.

For a rolling endpoint r=t-1 and window length L, graph-feature rolling regressions use samples from t-L+1 to t-1 with observed topology and the common ridge floor 10^-6. After fitting native graph-feature coefficients, every projected graph-feature row is evaluated through the projected operator

$$
\widehat{M}_{r}(W)=\widehat{A}_{r}+\widehat{B}_{r}W.
$$

Prediction uses the same projected object to map the endpoint state into the next outcome. Higher-order graph features are collapsed through the reference topology used at the endpoint before response evaluation. The benchmark instability column uses the unscaled projected effective operator and the implemented spectral-norm proxy; finite-horizon response errors then apply the common response-stability scaling separately.

The projected graph-feature stress tests ask whether graph-feature dynamics can be projected into the same direct/network response protocol. Their mappings are fixed as follows.

1. Sparse network TVP-VAR applies entrywise soft-thresholding with threshold 0.025. If the local network-VAR fit gives direct and network blocks, the projection applies the same soft-thresholding map to each block.
2. Graph-convolution VAR fits the next outcome on an intercept, the lagged outcome and the observed-topology lagged exposure. The projection discards the intercept and keeps the diagonal direct and network feature coefficients.
3. Graph neural VAR fits the lagged outcome, the observed-topology lagged exposure and their nonlinear graph-neural transforms. The projection adds the nonlinear direct block to the direct block and adds the nonlinear network block to the network block.
4. Diffusion graph VAR adds a second-order graph-diffusion exposure. The projection keeps the direct block and folds the diffusion block through the endpoint reference topology into the network block.
5. Recurrent graph-filter VAR adds a fixed rolling memory feature. The projection folds the direct memory term into the direct block and the network memory term into the network block. The 0.20 memory recursion constructs the fitted feature and is not carried as a separate state in the reported direct/network response.

Supplementary Table 3 gives row-level replication coverage. The main CP-network/local scale comparisons supporting the recovery claim use the replicated N=15 and N=30 rows. The CP-network, unrestricted local, Tucker-network and low-rank reduced-form N=50 rows are four-replication bounded stress checks. The graph-feature N=50 rows are bounded stress outputs with their own disclosed coverage. Projected graph-feature rows are included in the same replication table. Their N=15, N=30 and topology-stress rows are matched to the 20-replication protocol. Supplementary Table 1b records the corresponding tuning and projection rule. These rows should be read with their instability rates and projection step.

Benchmark stability is evaluated directly. For finite-horizon GIRF and network-component error calculations, both true and fitted effective operators are projected inside the same response-stability convention when the benchmark stability proxy would otherwise make the finite-horizon recursion explode. The unscaled effective operator is still used to compute the reported instability percentage. A method can have a finite GIRF error and a high instability rate; this combination indicates unstable propagation operators under the benchmark.

The collapsed-operator and low-rank no-network baselines define reduced-form comparison targets. Collapsed-operator CP is the direct preservation ablation: it smooths the total map after the topology argument has been absorbed, placing direct-only and frozen-topology recursions outside that reconstructed object. The no-network baseline separates reduced-form denoising gains from preservation of an explicit network-mediated channel. A lower error for either reduced-form comparator on a reduced-form column indicates an easier total-map denoising problem. The sparse, graph-convolution, graph neural VAR, diffusion graph VAR and recurrent graph-filter VAR rows test whether local graph-feature structure without block-preserving low-rank temporal reconstruction recovers the reported measurement target after projection. They are stress tests under the reported operator-recovery protocol, not native graph-learning benchmarks.

Projected neural, diffusion and recurrent graph-feature stress rows are evaluated after projection to the direct/network operator form used by the paper. Their replication coverage, projection rules and native instability rates are part of the reported benchmark evidence.

The stress grid also includes missing observed network edges and noisy observed network weights. These scenarios connect the benchmark to data-driven network-dynamics inference, where the observed topology can be incomplete or measured with error. Each scenario perturbs the analyst's observed topology while preserving the same data-generating propagation model. The high-topology-volatility, missing-edge and noisy-weight scenarios use at least 20 replications for CP-network, Tucker-network, collapsed-operator CP, low-rank no-network and the projected graph-feature stress rows. The comparison separates preserved-operator recovery from reduced-form smoothing and projected graph-feature structure. CP-network and Tucker-network preserve the direct/network tensor and can report network-component and frozen-topology errors. Collapsed-operator CP and low-rank no-network smooth reduced-form targets, placing those structural outputs outside their reconstruction targets. Within the preserved class, CP-network is more stable in this benchmark, with stress-scenario instability range 4.3-5.1% compared with 48.5-55.1% for Tucker-network. The projected graph-feature stress rows report two layers: 100.0% instability for the unscaled projected effective operators in these stress scenarios, and projected response errors after mapping the fitted graph-feature structure to the common direct/network protocol.

Among estimators that preserve the separated direct/network operator and supply all topology-switching endpoints, CP-network shows lower effective-operator, network-component, frozen-topology and GIRF error than unrestricted local rolling estimation on the replicated N=15 and N=30 rows when rank selection is adequate. The four-replication N=50 non-graph rows are reported as bounded stress checks. The matched-replication recovery claim rests on the N=15 and N=30 rows; projected graph-feature N=50 outputs are bounded stress results with row-level coverage disclosed in Supplementary Table 3. Forced rank under-specification is a failure mode for the CP-network path. Raw pair-level contribution recovery remains difficult and becomes especially fragile under rank under-specification, fast topology drift, sparse misspecified networks and noisy topology measurements. Those weaker raw pair-level results mark the limit of fine-grained attribution in this benchmark.

### Stricter endpoint-aware recovery gate

A later prespecified endpoint-aware experiment tested whether the favourable original scale benchmark extends to native held-out endpoints. This experiment used N=20, T=200 simulation cells and required one fixed candidate to pass both endpoints in all required cells. The post-remediation audit found no numerical or procedural integrity failure, but the scientific gate failed.

| Candidate | Required cells passed | Matched-design cells | Native-design cells | Promotion status |
| --- | ---: | ---: | ---: | --- |
| CP anchor split, rank 3 | 0/16 | 0/8 | 0/8 | Not promoted |
| Tucker anchor split, rank (3,3,3) | 6/16 | 6/8 | 0/8 | Not promoted |

This negative result does not erase the original N=15/N=30 comparison because the protocols and designs differ. It restricts claim inheritance: the original gains remain evidence for those controlled rows and the unrestricted rolling comparator, but they do not establish broad endpoint-aware or native held-out recovery. Endpoint availability, matched-design recovery and native-design recovery are therefore reported as separate claims.
