For each target date, unrestricted local rolling estimation regresses $y_s$ on the concatenated direct lag $y_{s-1}$ and network lag $W_{s-1}y_{s-1}$ within the declared window. A ridge term of $10^{-6}$ is added to the normal equations. This returns a sequence of full direct and network blocks, which is stacked as an $N\times 2N\times T_{roll}$ coefficient tensor. The unrestricted local path is the primary recovery comparator.

A local weak-separation diagnostic accompanies the baseline rolling design. For each rolling window and equation, the joint matrix containing all $p$ network-exposure lag blocks is residualized on the intercept, all $p$ direct lags and any optional exogenous regressors; the controlled benchmark declares no optional exogenous regressors. The diagnostic uses exactly the same lag-specific topology matrices supplied to the estimator and does not renormalize them. The residualized joint exposure Gram matrix is divided by the number of residual rows, and its minimum eigenvalue records the weakest network-lag direction left after removing the nuisance/direct span. A rolling-window equation is flagged when this value is at or below 1e-8; this cutoff is a within-design numerical singularity screen, not a cross-panel effect-size scale. The spectral condition number is reported as infinite when the residualized design is rank deficient or its minimum eigenvalue is at or below 1e-12; reported medians and quantiles use finite values, while the flag rate retains the degenerate cases.

The CP implementation reconstructs this separated tensor at the scenario rank. The controlled benchmark CP implementation performs a fixed count of 60 alternating-least-squares iterations when the call completes normally. It does not monitor an objective or residual and has no convergence tolerance or early-stop predicate. The $10^{-6}$ value regularizes the Gram systems; it is not a stopping tolerance. An exception aborts the call and is recorded as a reconstruction failure. These implementation semantics do not establish convergence or global optimality. Columns of the first two factor matrices are normalized after each iteration, with their scale transferred to the temporal factor. Reconstruction retains the direct/network mode: the first $N$ columns define $\widehat A_t$ and the second $N$ columns define $\widehat B_t$. The evaluated operator is therefore $\widehat M_t(W)=\widehat A_t+\widehat B_tW$ for any supplied topology in the declared query.

Comparator roles are assigned by the fitted object they return. Tucker reconstruction smooths the same separated tensor at matched multilinear rank and is a same-endpoint representation comparator. Collapsed-operator CP first forms the local total map $\widehat A_t+\widehat B_tW_t$ and smooths that tensor. Low-rank no-network reconstruction fits only the direct lag. These two reduced representations are scored on total-map, total-response and one-step-prediction endpoints; direct-only, frozen-topology and network-component endpoints require a separately verified inverse or retained separated blocks. Sparse and graph-feature rows use the fixed projections stated in Supplementary Table 1b and remain supplementary protocol diagnostics rather than native graph-learning rankings. A separate frozen native-comparator audit uses a distinct full-operator/finite-horizon registry; its role labels are recorded in the supplementary audit boundary and are not aliases for, or additional rows in, the active CP, Tucker or unrestricted-local benchmark.

The preservation ablation uses the same local estimates and changes only the reconstruction target. Although Corollary 1 identifies a diagonal class in which a rowwise inverse can recover separated coefficients, the collapsed benchmark neither restricts its smoothed full-matrix map to that image nor applies such an inverse. For the collapsed and no-network controls in this ablation, network-component and frozen-topology outputs are marked `OUTSIDE TARGET` before numerical comparison. This mark means that the fitted representation does not return the requested readout; it is not a zero error, a missing observation or a failed estimate.

In the controlled simulation benchmark, all methods are evaluated against objects generated by the declared data-generating process. Effective-operator error compares reconstructed paths with the corresponding DGP-generated $A_t+B_tW_t$ paths, and response error compares horizon-truncated unit-shock responses under the same topology, horizon and response-stabilization rule. These objects provide simulation truth within the declared design; they are not independent empirical ground truth, empirical calibration evidence or evidence of general performance. For the original released benchmark, declared unscaled-instability and failure fields travel with each row where specified; runtime or memory claims require an explicitly bound field and are not supplied by the separate audit.
