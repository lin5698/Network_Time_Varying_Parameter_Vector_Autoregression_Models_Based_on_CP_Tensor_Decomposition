For each target date, unrestricted local rolling estimation regresses $y_s$ on the concatenated direct lag $y_{s-1}$ and network lag $W_{s-1}y_{s-1}$ within the declared window. A ridge term of $10^{-6}$ is added to the normal equations. This returns a sequence of full direct and network blocks, which is stacked as an $N\times 2N\times T_{roll}$ coefficient tensor. The unrestricted local path is the primary recovery comparator.

The CP implementation reconstructs this separated tensor at the scenario rank. Alternating least squares updates the three factors with matched row-major unfoldings and Khatri-Rao orders, a $10^{-6}$ Gram regularizer and 60 iterations. Columns of the first two factor matrices are normalized after each iteration, with their scale transferred to the temporal factor. Reconstruction retains the direct/network mode: the first $N$ columns define $\widehat A_t$ and the second $N$ columns define $\widehat B_t$. The evaluated operator is therefore $\widehat M_t(W)=\widehat A_t+\widehat B_tW$ for any supplied topology in the declared query.

Comparator roles are assigned by the fitted object they return. Tucker reconstruction smooths the same separated tensor at matched multilinear rank and is a same-endpoint representation comparator. Collapsed-operator CP first forms the local total map $\widehat A_t+\widehat B_tW_t$ and smooths that tensor. Low-rank no-network reconstruction fits only the direct lag. These two reduced representations are scored on total-map and total-response endpoints only unless a separately verified inverse is supplied. Sparse and graph-feature rows use the fixed projections stated in Supplementary Table 1b and remain supplementary protocol diagnostics rather than native graph-learning rankings.

The preservation ablation uses the same local estimates and changes only the reconstruction target. Although Corollary 1 identifies a diagonal class in which a rowwise inverse can recover separated coefficients, the collapsed benchmark neither restricts its smoothed full-matrix map to that image nor applies such an inverse. Network-component and frozen-topology outputs are consequently outside that ablation's declared target. This endpoint assignment is made before numerical errors are compared.

All methods are evaluated against the known generating objects. Effective-operator error compares the reconstructed and true $A_t+B_tW_t$ paths. Response error compares their horizon-truncated unit-shock response paths under the same topology, horizon and response-stabilization rule. Runtime, memory, unscaled instability and failure records travel with each benchmark row, but they are not used to redefine endpoint availability.
