This note is a reproducibility boundary, not a data- or code-availability declaration. The present source does not claim that a public repository, DOI, licence, redistributable application data set or independently reproducible empirical workflow exists. `PAPER_CLAIM_AUDIT=BLOCKED` and `EMPIRICAL_IMPLEMENTATION_AUDIT=FAIL` prohibit such a claim for the RCEP and NYC execution candidates.

A releaseable controlled-benchmark package would need to bind the exact source revision, dependency environment, random-seed protocol, benchmark configuration, raw benchmark summaries and manuscript-facing figures/tables. A releaseable application package would additionally need to bind the provider-governed input route, transformation specification, helper version, source-file hashes, execution parameters, derived outputs and independent value-and-claim audit record. Static trust validation of a helper is not evidence that an application output is correct.

The original providers govern access to macroeconomic, trade, tariff, input-output and mobility sources. Their access terms cannot be replaced by an acquisition note or by a derived artifact. No current source statement asserts that raw sources are redistributed, that derived application panels are releaseable, that a fresh empirical run can be performed or that manuscript figures can be regenerated from an external package.

Before any availability statement is activated, the authors must choose and document a repository, persistent identifier, licence, access terms, package contents and excluded provider-governed materials. Those decisions are not made in this draft. Until then, this note records what a reproducibility claim would require rather than making one.
