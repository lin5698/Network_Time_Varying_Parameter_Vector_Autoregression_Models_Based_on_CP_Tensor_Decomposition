Dear Editors,

I submit "When reconstructed network models retain topology-dependent responses" for consideration as an Article in Nature Computational Science.

Evolving weighted networks often require a response query in which shocks, horizons and fitted coefficients stay fixed while the exposure graph changes. A collapsed dynamic map alone does not supply that query unless the model also specifies an identified inverse to admissible direct and network blocks. This manuscript defines a topology-switchable finite-horizon response operator, `M_{k,t}(W)=A_{k,t}+B_{k,t}W`, that keeps the direct block, network-mediated block and topology argument separately evaluable after reconstruction. The central contribution is query preservation: one reconstructed coefficient path can be read under observed topology, zero network mediation and a frozen benchmark topology.

Controlled benchmarks test whether this preserved object remains measurable and recoverable under a declared comparison contract. In replicated N=15 and N=30 settings, the CP-network implementation reduces effective-operator error by 93.6-96.8% and generalized impulse-response error by 82.5-87.3% relative to unrestricted local rolling estimation. A collapsed-map ablation preserves total responses and places network-component and frozen-topology endpoints outside its declared target because it estimates no inverse to separated blocks. Tucker and projected graph-feature stress rows evaluate the same endpoint contract under declared comparison scopes. Supplementary Table 1d documents target alignment, tuning, projection, replication coverage, stability handling and endpoint hierarchy. CP is the implementation layer in these tests; preservation of the topology argument is the reusable computational target.

Two empirical panels act as bounded operator-readout demonstrations outside the benchmark. The RCEP trade network illustrates fixed-path topology substitution and separates that readout from re-estimated uncertainty; the re-estimated coefficient-difference interval crosses zero and defines the empirical boundary. The public NYC Taxi panel implements the same aggregate, frozen-topology and GIRF outputs in a second weighted-network domain and returns a near-null aggregate topology contrast on a stable retained-date path. These panels show what the preserved operator returns under two exposure systems. Policy-effect identification, topology formation, broad domain generality and regime switching require separate designs.

Code, derived analysis inputs, environment specifications and random-seed conventions accompany the submission. These materials regenerate the reported figures and tables at the 500-draw bootstrap setting and support fresh reruns under the documented parameters. Reconstruction from original source files depends on the third-party access conditions stated in the manuscript.

The manuscript fits Nature Computational Science as a representation-level contribution for dynamic networked systems. Temporal-network methods have shown that the fitted representation determines which communities, memory patterns, predictions or contagion dynamics remain measurable. This manuscript brings that computational principle to response analysis: topology-substitution readouts remain available after temporal regularization only when the fitted object keeps the supplied topology argument exposed. The advance is an endpoint-preserving response representation that turns this recurring query into a reproducible computation. The expected readership includes researchers in network science, computational social science, time-varying multivariate modelling, graph-based inference and applied complex systems.
