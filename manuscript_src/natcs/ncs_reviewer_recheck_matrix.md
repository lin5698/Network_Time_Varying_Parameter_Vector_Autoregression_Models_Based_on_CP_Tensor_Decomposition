## 5. Key Replacement Snippets

Use these only if future edits or reviewer responses need a concise statement.

### Senior editor scope response

The manuscript's NCS contribution is representation-level. A topology-substitution response is only computable after smoothing if the fitted object preserves the supplied topology argument. The topology-switchable response operator makes observed-topology, direct-only and frozen-topology readouts evaluable from one reconstructed path. CP is the implementation used in the reported benchmarks; query preservation is the transferable computational target.

Tags: novelty / significance / clarity.

### Methods-reviewer comparator response

The benchmark is organized around the response endpoint. Each fitted object first passes or fails the endpoint-availability gate. Numerical recovery is scored only for readouts that belong to that object's declared target. The projected graph-feature rows are operator-recovery stress tests after projection; they are not presented as native temporal-GNN forecasting rankings.

Tags: rigour / reproducibility / clarity.

### Domain-reviewer RCEP boundary response

The RCEP panel is a fixed-path topology-substitution readout. It evaluates observed and 2016-2019 benchmark topology while holding the fitted coefficient path, shock normalization and horizon fixed. The moving-block re-estimation interval and stability diagnostics define the boundary for interpreting direction and amplitude. The analysis does not identify tariff-policy claims or topology formation.

Tags: rigour / significance / clarity.

### Reproducibility response

The reviewer archive regenerates manuscript-facing evidence from shipped derived objects, including tables, figures and numerical summaries. The final gate checks active package locality, archive checksums and release-safety scan outputs before upload-freeze hashing. Raw-to-derived rebuilding is documented separately because several source blocks depend on third-party access conditions and helper checkouts. The submission claim is evidence-complete derived-object reproducibility, not fully self-contained raw-data redistribution or legal redistributability.

Tags: reproducibility / rigour / clarity.

### Fig. 2 visual response

Fig. 2 should be kept only if the journal portal keeps panel a readable or allows comfortable standalone PDF/SVG inspection. If the portal rasterizes the figure or blocks source inspection, the redesign contract should enlarge the endpoint gate and move secondary stress details to Supplementary.
