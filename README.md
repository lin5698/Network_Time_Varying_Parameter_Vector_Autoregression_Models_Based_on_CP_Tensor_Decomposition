# Network Time-Varying Parameter VAR with CP Tensor Decomposition

This private repository tracks the auditable manuscript sources, experiment protocols, analysis scripts, tests, and Nature Computational Science revision records for the project.

Raw or restricted data, generated evidence, compiled manuscripts, reviewer archives, and temporary dependencies are intentionally excluded from Git. Their provenance and access boundaries are documented in `manuscript_src/natcs` and the experiment audit records.

## Key entry points

- `manuscript_src/natcs/`: source-of-truth manuscript sections and submission metadata
- `scripts/`: evidence builders, experiment implementations, figure builders, and package checks
- `tests/`: manuscript and evidence consistency tests
- `refine-logs/`: frozen experiment protocols and result-to-claim records
- `docs/superpowers/specs/`: approved experiment and implementation designs
- `NCS_STRATEGY_REVIEW_20260716.md`: current NCS-level strategy review

The current dual-track experiment design is `docs/superpowers/specs/2026-07-16-r006e-r006f-dual-track-design.md`. Formal R006e/R006f outcomes are not authorized until their construction-only tests pass and pre-outcome provenance artifacts are frozen.
